# Tech Oasis School logo kit

| File | Use it for |
|---|---|
| `tech-oasis-logo.svg` / `.png` | Full logo for light backgrounds (letters, documents, website, slides) |
| `tech-oasis-logo-white.svg` / `.png` | Full logo for dark or green backgrounds |
| `tech-oasis-mark.svg` / `.png` | Symbol only, for light backgrounds (stamps, watermarks, small spaces) |
| `tech-oasis-mark-light.svg` / `.png` | Symbol only, for dark backgrounds |
| `tech-oasis-app-icon.svg` / `.png` | Square icon on brand green (social profile picture, app icon) |
| `tech-oasis-favicon-180.png` | Browser tab / phone home-screen icon |
| `tech-oasis-social.png` | 1200 × 630 link-preview image (WhatsApp, Facebook, LinkedIn, X) |
| `tech-oasis-emblem-animated.svg` | The animated "vault" emblem from the admin sign-in; plays in any modern browser |

PNG files have transparent backgrounds (except the app icon, favicon and social image) and are large enough for print:
the full logo is 2400 px wide, the symbol 1024 px tall.

**Use the SVG files whenever you can.** They stay sharp at any size. The SVG lettering uses the Inter typeface
(free from Google Fonts); on a computer without Inter it falls back to a similar font. The PNGs have the exact lettering
built in.

## Colours

| Name | Hex |
|---|---|
| Forest (symbol, light backgrounds) | `#225A50` |
| Teal (symbol, dark backgrounds) | `#3A8D7C` |
| Deep green (backgrounds) | `#0C3B2E` |
| Ink (text) | `#0A1F1A` |
| Gold ("OASIS", accents) | `#C4A649` |
| Cube faces | `#DEC45B` (top) · `#AC903F` (left) · `#937733` (right) |

Fonts: **Inter** (logo lettering and body text) and **Fraunces** (headings).

Keep clear space around the logo of at least the width of the gold cube, and don't stretch, recolour or rotate it.
